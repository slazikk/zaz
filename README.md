# Zvuk Music for iOS

Нативный SwiftUI-клиент для API сервиса «Звук». Проект использует iOS 17+, `AVFoundation` для потокового воспроизведения и Keychain для локального хранения пользовательского токена.

## Что реализовано

- вход с `X-Auth-Token` (он не добавляется в исходный код);
- быстрый поиск треков, исполнителей, релизов и плейлистов;
- воспроизведение треков в качестве FLAC → High → Mid;
- компактный плеер и пауза/продолжение;
- добавление/удаление трека из избранного на уровне API;
- экран настроек и выход с удалением токена.

## Сборка IPA

1. На Mac с Xcode 15+ установите [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`.
2. В каталоге проекта выполните `xcodegen generate`, затем откройте `ZvukMusicIOS.xcodeproj`.
3. Выберите команду разработчика и уникальный Bundle Identifier (`com.yourcompany.zvukmusic`).
4. Подключите физический iPhone, выберите его схемой запуска, затем выберите `Product → Archive` и в Organizer — `Distribute App`.

Для App Store потребуется разрешение правообладателя/договор с сервисом «Звук» и соблюдение его условий API. Этот проект не содержит чужой музыки или учётных данных.

## Сборка без Mac — GitHub Actions

В `.github/workflows/build-unsigned-ipa.yml` уже есть workflow для облачной сборки на macOS-раннере GitHub. Загрузите содержимое этой папки в **свой** GitHub-репозиторий, затем откройте **Actions → Build unsigned IPA → Run workflow**. После завершения скачайте артефакт `ZvukMusicIOS-unsigned-ipa` и перетащите IPA в Sideloadly на Windows.

Sideloadly подпишет приложение вашим Apple ID при установке. С бесплатным Apple ID подпись обычно действует 7 дней, после чего приложение нужно установить/подписать заново. Используйте отдельный Apple ID для тестирования.
